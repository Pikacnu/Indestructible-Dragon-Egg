> Actually I Don't know how to name it due to this plugin is build for my friend and I add more function base on his Idea.

### [!] This is a paper plugin 

## How To Use?

go to release,
download the jar.
put jar in plugin (paper only)

## Functions:

1. Command To Get Compass Which Will Pos to Player That Hold DragonEgg. `/degg give compass`
2. Make DragonEgg None Destroyable (At Least won't disappear in void, catus and lava)
3. Compass Can open bossbar indicator to get the holder position.
4. bossbar indicator will show distance by change progess and color.

## How it works?

The Dragon's Egg is Resistant on All DamageTypes.
So it won't be destory by item type(Entity).

And if the Egg fall into void.  
It will float under the bedrock to prevent minecraft kill it.  
And it will try to teleport to player which is nearest to make sure it is keep by player.
